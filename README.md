# Small Business Command Center

A React and Laravel application for managing small-business operations, including orders, products, customers, expenses, and pricing.

## Local setup

See [README_LOCAL.md](README_LOCAL.md) for the verified local startup instructions, configuration notes, and test commands.

- Frontend: React with Vite
- Backend: Laravel 12 and PostgreSQL

The local environment file, dependencies, generated frontend build, and private uploads are excluded from Git.
